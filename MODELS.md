# Models

Every model the recipes call, with the recipes that use it. All of them are open-weight models served
by [SIE](https://github.com/superlinked/sie). The id is what goes in a recipe's `rules.yaml`, the
same on SIE Serverless, SIE Cluster and SIE Local. "Image" is the SIE v0.10.1 image that serves the model
when you host it yourself (see [SELF_HOSTING.md](SELF_HOSTING.md)). Check each license on the
model card before you rely on it. The recipes in `agentic/` also use Claude to run their agent loop:
it's called through the Anthropic API with your own key, not served by SIE, so it isn't in this table.

## Swaps we ran

Between 31 Oct and 4 Nov 2026 (the date is in each recipe's README) we swapped one model at a time in each recipe's `rules.yaml` and ran the recipe using
SIE Serverless with nothing else changed. A row that says a swap did not run was checked but not run.
Each recipe README's "Try another model" section has the details. The short version:

| Default | Swap | How it went |
| --- | --- | --- |
| `Qwen/Qwen3-Reranker-4B` | `Qwen/Qwen3-Reranker-0.6B` | Same statuses in search_clinical_guidance, check_contracts_for_required_clauses, answer_questions_on_new_filing, check_citations_against_sources and match_alerts_to_runbooks. In create_coverage_brief_for_claim it sent the no-match claim to the LLM and two claims came out quote_not_found; keep_facts_current_from_notes dropped one fact (9 of 10). Clearly worse where many close candidates compete (categorize_products_into_taxonomy, map_financial_statements_to_template, rerank_search_within_filters). Its scores crowd near 1.0, so check `min_score` and margins |
| `Qwen/Qwen3-Reranker-4B` | `tencent/R3-rerank-0.6b` | Usually keeps the order but squeezes scores into about 0.2 to 0.8. check_citations_against_sources kept the same statuses (best scores 0.78 to 0.82, above its 0.5 bar); elsewhere the thresholds stop separating good from poor matches and need resetting |
| `Qwen/Qwen3-Embedding-4B` | `tencent/R3-embedding-0.6b`, `Snowflake/snowflake-arctic-embed-l-v2.0` | Fine for retrieval in keep_facts_current_from_notes. ## Other models

SIE serves over 200 models: embedders, rerankers, extractors, OCR, detectors, guards and LLMs.
[`packages/sie_server/models`](https://github.com/superlinked/sie/tree/main/packages/sie_server/models)
has one config per model, and [superlinked.com/models](https://superlinked.com/models?utm_source=github&utm_medium=docs&utm_campaign=sie-cookbook&utm_content=models) lists them by
task. SIE Serverless serves a subset; the full list is at `GET https://api.superlinked.com/v1/models`
with your API key.
